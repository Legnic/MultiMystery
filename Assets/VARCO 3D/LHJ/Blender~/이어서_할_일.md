팀원 요청: "동작은 그대로 두고, 메시가 뭉개지는 것만 최대한 없게."

## 블렌더에서 직접 고치는 방법

파일: `Blender~/캐릭터_몸통다듬기.blend` (`~`가 붙은 폴더라 유니티에는 안 보여요)

- 두 캐릭터의 **몸통 점들만 미리 골라 둔** 파일이에요. 점프 웅크린 순간(57번째 장면)에 맞춰져 있어요.
- 캐릭터마다:
  1. 몸을 클릭하고 왼쪽 위 칸을 **Weight Paint**로 바꿔요.
  2. 위쪽 줄 왼쪽의 **점 모양 아이콘(Vertex Selection)**이 켜져 있는지 확인해요. (골라 둔 몸통만 바뀌게 해 줘요)
  3. **Weights → Smooth**를 눌러요. 왼쪽 아래 설정 창에서 **Subset: All Groups / Factor: 1 / Iterations: 10**으로 바꿔요.
  4. **Object Mode**로 돌아와서 주름이 줄었는지 확인해요. 타임라인을 앞뒤로 움직여 봐요.
  5. **Ctrl+S**로 저장해요.
- 갈라진 선이 보이면: Edit Mode → **Mesh → Clean Up → Merge by Distance**로 이음새를 붙인 다음 다시 다듬어요.
- 다 하면 Claude에게 "몸통다듬기 블렌더 파일 유니티에 넣어줘"라고 말해요.

## Claude용 메모

- 원본 작업 폴더 `C:\@Dev\Character3D`는 회사 컴퓨터에만 있어요. 만드는 순서는 `Blender~/tools/make_rigged3.py`를 참고해요.
  - 마지막으로 쓴 설정: `SPINE_KEEP=0.4 SPINE_KEEP_Jump=0.1 ARM_OUT=10 ARM_OUT_Jump=18 ARM_OUT_Run=14 OBJ_NORMALS=1 FIX_LEAK=1 FIX_TORSO=1 FIX_SEAMS=1 WEIGHT_SMOOTH=15` (TORSO_DROP 0.06, BAND_LO 0.10, 걷기 -52도 회전)
- 유니티에 다시 넣을 때: FBX 클립 이름을 Walk/Run/BackWalk/Jump/Stand로 맞추고, 반복 구간은 Walk 29-107, Run 71-148, BackWalk 45-109, Jump 45-105(반복 안 함)로 둬요. 애니메이터는 `Char_*_Anim.controller`의 상태 동작을 새 클립으로 다시 연결해요.
- 팀 공용 설정(QualitySettings, URP, ProjectSettings)은 바꾸지 말아요. 시험하다 바꾼 설정은 반드시 되돌려요.
- 사용자는 쉬운 한국어 설명과 사진(전/후 비교)을 좋아해요. 부탁한 것만 고쳐요.
