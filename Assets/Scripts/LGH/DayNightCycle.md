# LGH 방 - 채광(주야간 조명) 시스템 문서

`DayNightCycle.cs` (Assets/Scripts/LGH)가 어떤 원리로 낮/밤 채광을 만들어내는지 정리한 문서입니다. 팀원이 이 스크립트를 참고하거나 다른 방에 비슷한 걸 적용할 때 참고하세요.

## 개요

- 1분(기본값, `Day Length Seconds`로 조절 가능) 동안 하루 전체가 반복되는 Play 모드 전용 테스트 스크립트입니다.
- 새벽 → 아침 → 낮(정오) → 오후 → 저녁(일몰) → 황혼 → 밤 → 깊은 밤 순서로 순환하고, 한 바퀴 끝나면 다시 새벽으로 돌아옵니다.
- Edit 모드에서는 동작하지 않습니다(Play를 눌러야 확인 가능).

## 좌표계 / 방향 규칙

방을 만들 때 정한 규칙입니다.

| 방향 | 월드 축 |
|---|---|
| 남쪽 (창문이 있는 벽) | +Z |
| 북쪽 | -Z |
| 동쪽 | +X |
| 서쪽 | -X |

창문이 있는 벽(+Z)을 \"남향\"으로 정의했습니다. 실제 한국 주택에서 남향 창이 채광에 유리한 것과 같은 원리로, 정오 무렵 해가 남쪽 하늘 높이 떠서 창문을 정면으로 관통하며 가장 강하게 빛이 들어오도록 설계했습니다.

## 시간 파라미터

- `t01` : 0~1 사이 값. 하루 진행도를 나타냅니다.
  - 0.00 = 새벽 시작
  - 0.25 = 정오
  - 0.50 = 일몰
  - 0.75 = 한밤중
  - 1.00 = 다음 날 새벽(= 0.00과 동일한 상태로 순환)
- `Day Length Seconds` : 하루 전체 길이(초). 기본 60초.
- `Start Time 01` : Play를 눌렀을 때 시작 시간대(기본 0.2, 아침 중반 근처).

## 태양 위치 계산 (방위각 + 고도각)

매 프레임 `t01`로부터 태양의 방위각(azimuth)과 고도각(elevation)을 계산하고, 이 둘로 빛의 방향 벡터를 구해 Directional Light를 회전시킵니다.

```
azimuth  = 90 - t01 * 360 + azimuthOffset
elevation = maxElevation * sin(t01 * 2pi)
```

- **azimuth**: 동(90개, t=0) → 남/창문 정면(0개, t=0.25, 정오) → 서(-90개, t=0.5)로 스윕합니다.
- **elevation**: 사인 곡선 한 바퀴로, 낮 동안(t 0~0.5)은 양수(지평선 위), 밤 동안(t 0.5~1.0)은 음수(지평선 아래)입니다. 정오(t=0.25)에서 `Max Elevation`(기본 52개)로 최고점을 찍습니다.

이 두 각도를 아래 식으로 \"빛이 이동하는 방향\" 벡터로 변환합니다.

```
travelDir = ( -sin(az)*cos(el), -sin(el), -cos(az)*cos(el) )
sunLight.transform.rotation = Quaternion.LookRotation(travelDir, Vector3.up)
```

이 벡터의 Z성분이 음수(+Z → -Z로 이동)일수록 창문을 통해 방 안으로 빛이 들어오는 형태가 되고, 정오 부근에서 이 값이 가장 크게(마이너스로) 나와 창문 관통광이 하루 중 가장 강해집니다. 반대로 새벽/일몰처럼 해가 동/서 쪽에 거의 수평으로 있을 때는 창문과 거의 평행한 각도라 빛이 옆에서 스치듯 들어오며 약해집니다 - 실제 남향 창이 아침/저녁보다 한낮에 가장 밝은 것과 같은 원리입니다.

## 밝기 / 색상 타임라인

`Gradient`(색)와 `AnimationCurve`(세기)로 시간대별 값을 보간합니다. (Unity Gradient는 색상 키를 최대 8개까지만 지원해서, 8개 구간으로 압축했습니다.)

| 시간대 | t01 | 태양광 색상 | 태양 세기 | 비고 |
|---|---|---|---|---|
| 새벽(동쪽) | 0.00 | 주황빛 (1.00, 0.75, 0.55) | 0.5 | |
| 아침 중반 | 0.10 | (1.00, 0.85, 0.65) | 1.3 | |
| 정오(남향, 최고점) | 0.25 | 밝은 화이트 (1.00, 0.96, 0.88) | 2.8 | 하루 중 최대 세기 |
| 오후 | 0.40 | (1.00, 0.85, 0.65) | 1.6 | |
| 일몰(서쪽 노을) | 0.50 | 붉은 노을 (1.00, 0.45, 0.25) | 0.7 | |
| 황혼 | 0.62 | 보랏빛 (0.30, 0.22, 0.35) | 0.10 | |
| 밤 | 0.75 | 어두운 남색 (0.12, 0.15, 0.30) | 0.0 | 태양 자체가 꺼짐 |
| 깊은 밤 | 0.90 | (0.06, 0.07, 0.16) | 0.0 | |

세기가 0.015 이하로 떨어지면 `sunLight.enabled = false`로 아예 꺼버립니다. 단순히 세기를 0에 가깝게 낮추는 게 아니라 광원 자체를 비활성화해서, 밤에는 태양광의 영향이 완전히 사라지도록 한 것이 포인트입니다.

## 앰비언트(주변광) & 안개

- `RenderSettings.ambientMode = Flat` : 스카이박스 대신 고정된 단일 색으로 전체 반사광(주변광)을 처리합니다.
- 앰비언트 색도 태양과 같은 타임라인으로 낮에는 밝고(정오 약 0.40 밝기), 밤에는 거의 암전(0.02~0.06)까지 떨어집니다.
- `fogColorGradient`는 앰비언트 색 그라디언트를 그대로 재사용해서, 안개 색도 시간대에 맞춰 같이 변합니다.

## 밤에 촛불에 의지하는 이유

태양광(직사광)과 앰비언트가 밤에 거의 0에 수렴하도록 설계했기 때문에, 밤 시간대에 방을 밝히는 건 사실상 협탁 위의 `Candle_Light`(항상 켜져 있는 Point Light) 하나뿐입니다. 이 부분이 \"낮=창문 채광, 밤=촛불\" 컨셉을 구현하는 핵심 로직입니다.

## 창문 유리 발광 연동

`Window_Glass` 머티리얼의 `_EmissionColor`를 매 프레임 아래처럼 갱신합니다.

```
glow = sunColor(t01) * lerp(0.08, 0.55, clamp01(intensity / 2.8))
```

낮에는 창문 자체가 은은하게 빛나 보이고, 밤에는 발광이 거의 사라져서 창문도 함께 어두워집니다.

## 인스펙터에서 조절 가능한 값

| 필드 | 설명 |
|---|---|
| Sun Light | 회전/색상/세기를 제어할 Directional Light (자동으로 \"Directional Light\" 오브젝트를 찾아 연결됨) |
| Window Glass Renderer | 발광을 갱신할 창문 유리 Renderer |
| Day Length Seconds | 하루 전체 길이(초). 기본 60 |
| Start Time 01 | Play 시작 시간대(0~1) |
| Max Elevation | 정오 태양 최고 고도(도). 기본 52. 너무 높이면(90에 가까울수록) 정오에 빛이 거의 수직으로 내려와 오히려 창문 관통광이 약해짐 |
| Azimuth Offset | 창문이 다른 벽으로 옮겨지면 이 값으로 방위를 보정 |

## 알려진 단순화 / 한계

- 실제 태양처럼 그림자 길이/방향이 정밀한 위경도 계산으로 나오는 게 아니라, 방 하나 기준으로 단순화한 방위각/고도각 모델입니다.
- Directional Light 하나만 사용하므로 여러 창문/벽에서 동시에 서로 다른 각도의 빛이 들어오는 건 표현하지 못합니다.
- 프로토타입/테스트 목적의 스크립트라 Play 모드에서만 동작합니다.
